# Project Guide: SMS Skill Project

This project implements the **SMS (Sessions Memory Skill)** to maintain continuity across AI sessions.

## Project Memory
This project uses the **SMS skill**. The AI is required to maintain a `status.md` file in the project root to track progress and state.

- **Skill Location**: `.claude/skills/sms.md`
- **Status File**: `status.md`

Please ensure that `status.md` is updated at the end of every major task or before ending the session to prevent context loss.
